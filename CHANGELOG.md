# Changelog

All notable changes to the Shinjuku theme are documented here.

## [1.0.0] — 2026-11-10

### Added

- Violet-black, neon-cyan palette with the Tokyo Night accent family.
- Cyan-to-violet 45° gradient borders for focused windows and shell cards.
- Full custom shell configuration: dark translucent bar, lighter flyouts,
  gradient notification rail, accent-tinted controls, translucent launcher,
  themed menus and polkit prompt, and a cyan lock screen input.
- Six 16:9 wallpapers in the rotation.
- Yaru Purple Dark icons and a cyan keyboard backlight color.
- Chromium chrome tint via `chromium.theme`.
- Desktop, lock screen, and palette preview images.
- Installation, palette, accessibility, and contribution documentation.
